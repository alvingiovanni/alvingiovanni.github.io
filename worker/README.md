# "Ask about this work" — the Worker

The static site never talks to Anthropic directly. It POSTs a question to this
Cloudflare Worker, which holds the API key, loads the site's own corpus
(`content/corpus.md`, regenerated by `tools/build-node-list.py` on every push),
sends it to Claude as a **cached system prompt**, and returns a short, cited
answer. No vector database: the whole body of work is a few tens of thousands of
tokens and fits in context.

## Cost

Haiku 4.5 is $1 per million input tokens, $5 per million output tokens, and cache
reads are about a tenth of the input price. A question is roughly 15–20k cached
tokens plus a 300-token answer, so about **$0.004 per question**. Three hundred
questions a month is a dollar or two; the daily cap of 200 bounds the worst
month at around $25. Switch `MODEL` to `claude-sonnet-5` for more judgment at
roughly twice the cost per question.

Set a **spend limit in the Anthropic console** as well. The caps in this Worker
are the fence; the console limit is the backstop.

## Deploy

```sh
cd worker
npm install
npx wrangler login
npx wrangler kv namespace create ASK_KV      # paste the id into wrangler.toml
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put RATE_SALT            # any long random string
npx wrangler deploy
```

Then put the Worker URL into `index.html`:

```js
window.PORTFOLIO_CONFIG = { agentEndpoint: "https://portfolio-ask.<you>.workers.dev" };
```

The "Ask about this work" button appears once that is set. Finally, remove
`draft: true` from `content/nodes/work/portfolio-agent.md` and
`content/details/portfolio-agent.md` so the write-up publishes.

## Guards

| Guard | Where | Default |
| --- | --- | --- |
| Origin check + CORS | Worker | the site's origin only |
| Per-reader limit | KV, hashed IP per hour | 10 questions / hour |
| Daily cap | KV | 200 questions / day |
| Answer length | `MAX_TOKENS` | 400 tokens |
| History | last 6 turns, 2,000 chars each | |
| Turnstile | set `TURNSTILE_SECRET` (and add the widget to the page) | off |
| Spend limit | Anthropic console | set it |

## The question log

Every question (never the reader) is written to KV under `q:<timestamp>:<id>`
with the answer, whether it was "not covered", which nodes were cited, and the
token usage, and expires after 90 days. It is the feedback loop: questions the
agent could not answer are the content that should be written next.

```sh
npx wrangler kv key list --binding ASK_KV --prefix q:
npx wrangler kv key get --binding ASK_KV "q:<key>"
```

## Local test

```sh
npx wrangler dev          # http://localhost:8787
curl -s http://localhost:8787 -H 'Content-Type: application/json' \
  -H 'Origin: http://localhost:8000' \
  -d '{"question":"Which projects used clustering?"}'
```

Twenty questions worth trying before going live: how incrementality was
separated from correlation; which projects used clustering; what the LTV
framework changed about pricing; what "not covered" looks like (ask about
something outside the portfolio); and a few that try to make it evaluate fit for
a job, which it should decline to do while still describing the relevant work.
